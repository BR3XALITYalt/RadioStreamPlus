Open source radio livestreaming

Radio livestreams, built around live SDRs.

Build continuous radio-monitoring broadcasts with public KiwiSDR receivers. RadioStream+ finds receivers for your signal, tunes them, rotates playback, and provides the player and information overlay for OBS.

Download RadioStream+

RadioStream+ prepares the receiver feed. OBS handles the scene and broadcasts to YouTube or another platform.

Find a live receiver

Locate public KiwiSDRs that cover the frequency you want to monitor.

Rotate automatically

Keep the monitoring feed moving between eligible receivers on a timer.

Send it to OBS

Capture the SDR player and information overlay, then stream the scene from OBS.

Get the application

Choose your download

Install RadioStream+ on the computer running your livestream. It supplies local browser sources for OBS; OBS handles the actual broadcast.

Run from source

Cross Platform (Python)

For Windows, macOS, and Linux. Download the source archive, extract it, then start RadioStream+ from a terminal.

Python 3.10 or newer

  • No bundled runtime or installer
  • Use py radiostream.py on Windows
  • Use python3 radiostream.py on macOS and Linux
