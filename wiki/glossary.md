# Glossary

**Navigation:** [Wiki home](main.md) · [Receiver Discovery](receiver-discovery.md) · [KiwiSDR](kiwisdr.md) · [OpenWebRX](openwebrx.md)

| Term | Meaning |
|---|---|
| AM | Amplitude modulation |
| CW | Continuous wave, commonly used for Morse code reception |
| Demodulation mode | The method used to recover audio from a radio signal |
| Frequency range | The lower and upper limits a receiver or SDR profile advertises |
| HF | High frequency radio spectrum, conventionally 3 to 30 MHz |
| KiwiSDR | A network-connected software-defined radio receiver platform |
| LSB | Lower sideband |
| NBFM | Narrowband frequency modulation |
| OpenWebRX | Browser-accessible software-defined radio receiver software |
| OpenWebRX+ | A maintained OpenWebRX variant with multiple receiver profiles and related features |
| Passband | The range of frequencies passed through the receiver's audio filter relative to the carrier |
| Preset | A named saved combination of frequency, mode, and passband |
| Receiverbook | A public directory that lists OpenWebRX receivers |
| SDR | Software-defined radio |
| SNR | Signal-to-noise ratio |
| USB | Upper sideband |
| WWV | NIST's time and frequency radio station |

## Project terms

- **Custom OpenWebRX instance:** A receiver URL and map location entered by the user.
- **Receiver preference:** A like, dislike, or block value attached to a KiwiSDR directory entry.
- **Rotation:** Automatic switching from one selected KiwiSDR receiver to another.
- **Search center:** The center point used to filter receiver locations by distance.
